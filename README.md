# **MirzaVibes Chat App**

A real-time chat application that allows users to communicate seamlessly. Built with a user-friendly interface, it’s perfect for staying connected with friends or teams.

---

## **Features**

- 💬 **Real-time Messaging:** Instant communication with smooth updates.


---

## **Installation and Setup**

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the server:
   ```bash
   npm run dev
   ```

3. Open the app in your browser:
   ```
   http://localhost:3000
   ```
